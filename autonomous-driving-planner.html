Autonomous Driving Local Planner with Reinforcement Learning

Built a closed-loop CARLA planning framework for highway merges, unprotected left turns, and sudden cut-ins, using global A* routing, fixed PID tracking, and a PPO local planner for interaction-aware trajectory generation.

Overview

This project targets high-conflict traffic situations where reactive rule sets often break down: highway merges, unprotected left turns, and abrupt cut-ins. I built the system as a controlled closed-loop study so planner improvements could be measured directly without changing the low-level vehicle controller.

Implementation

I developed the training and evaluation pipeline in Python using Stable-Baselines3, PyTorch, and CARLA. The stack keeps global A* route planning and longitudinal/lateral PID tracking fixed, then replaces the rule-based local planner with PPO. At each simulator step, the learned policy outputs a short-horizon local trajectory segment and target speed, allowing the vehicle to react to nearby traffic while staying anchored to the long-horizon route.

The observation design combined ego and route-following state, gap-level merge cues, and nearby-vehicle geometry. I also shaped the reward around progress, anti-idling behavior, collision avoidance, TTC safety, route adherence, and comfort penalties so the agent had to balance merge completion against smoothness and risk.

Results

In the tuned highway-merge evaluation, the PPO planner achieved an 86% success rate over 100 episodes, with a 17.4 s 90th-percentile completion time for successful runs and a 547.137 m/s^3 90th-percentile maximum jerk. That result showed the RL pipeline was functional end-to-end in closed loop, while also making clear that smoothness and decisiveness still needed more tuning.

My Contributions

  • Designed the hierarchical planner structure combining global A* routing, PPO local planning, and fixed PID tracking.
  • Built reproducible CARLA scenarios for highway merges, unprotected left turns, and sudden cut-ins.
  • Implemented observation features and reward shaping for gap selection, progress, safety, and ride comfort.
  • Developed evaluation tooling to benchmark success rate, crash rate, completion time, and jerk against CARLA baselines.

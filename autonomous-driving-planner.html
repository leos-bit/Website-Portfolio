Autonomous Driving Local Planner with Reinforcement Learning

Built a hierarchical autonomous-driving system in CARLA where a global A* planner provides route-level guidance and a PPO policy generates reactive local trajectories for highway merging and unprotected left turns.

Overview

The project targets driving scenarios that are difficult for fixed rule sets: dense highway merges and unprotected left turns with interacting traffic. I used a two-level planner so the agent could retain long-horizon route intent while still responding to local traffic conditions.

Implementation

I developed the training and evaluation pipeline in Python using Stable-Baselines3, PyTorch, and CARLA. The stack includes scenario generation, traffic-interaction features, reward design, rollout analysis, and repeatable benchmarking against CARLA rule-based baselines.

Results

The PPO planner achieved a 92% success rate and was benchmarked using completion time, jerk-based comfort metrics, and failure-mode analysis. The result was a planner that handled reactive maneuvers more reliably than hand-coded baselines in mixed-traffic settings.

My Contributions

  • Designed the hierarchical planner structure combining A* routing and PPO local control.
  • Built the training/evaluation pipeline, scenario tooling, and rollout analysis utilities.
  • Engineered reward functions and traffic-interaction features for merging and intersection behavior.
  • Benchmarked policy performance against CARLA rule-based baselines with comfort and failure metrics.

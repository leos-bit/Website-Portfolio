Real-Time Conveyor-Belt Object Detection and Robotic Sorting

Built a calibrated perception and robot-integration pipeline for mixed-object sorting on a conveyor in real time.

Overview

Mixed-item sorting on moving belts requires fast perception and robust translation from image coordinates to robot actions. The system needed to remain stable under frame-to-frame variation and class ambiguity.

Implementation

I built a Python vision stack using YOLO and OpenCV, refined object centroids with silhouette-based localization, and projected detections into world coordinates through homography calibration. The perception stack then fed a delta-arm robotic workflow for physical sorting.

Results

The pipeline reduced misclassification through confidence-weighted tracking, stabilized labels across frames, and expanded supported classes to bottles, cans, and six-pack bundles.

My Contributions

  • Built the calibrated detection and localization pipeline.
  • Integrated perception outputs with downstream robotic sorting workflows.
  • Programmed, assembled, and tested the delta-arm structure and associated control flow.

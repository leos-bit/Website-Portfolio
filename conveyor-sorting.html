Real-Time Conveyor-Belt Object Detection and Robotic Sorting

Built a calibrated perception and robot-integration pipeline for mixed-object sorting on a conveyor in real time.

Overview

Mixed-item sorting on moving belts requires fast perception and robust translation from image coordinates to robot actions. The system needed to remain stable under frame-to-frame variation, class ambiguity, and the practical constraints of downstream robotic handling.

Implementation

I built a Python vision stack using YOLO and OpenCV, refined object centroids with silhouette-based localization, and projected detections into world coordinates through homography calibration. The perception stack then fed a delta-arm robotic workflow for physical sorting. I also improved the training loop through rapid auto-labeling and retraining so the detector could adapt as the object set expanded.

Results

The pipeline reduced misclassification through confidence-weighted tracking, stabilized labels across frames, and expanded supported classes to bottles, cans, and six-pack bundles. The system combined robust localization with practical robotic integration so detections translated into usable sorting actions.

My Contributions

  • Developed the real-time YOLO and OpenCV pipeline for object detection on the conveyor.
  • Improved localization through silhouette-based centroid refinement and homography calibration.
  • Reduced misclassification with confidence-weighted tracking, label stabilization, and retraining workflows.
  • Programmed, assembled, tested, and integrated the delta-arm structure for downstream sorting.

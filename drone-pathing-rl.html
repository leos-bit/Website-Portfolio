Autonomous Drone Pathing with Reinforcement Learning

A MuJoCo quadrotor navigation project comparing PPO, SAC, and model-based RL in randomized 3D obstacle fields, with final modifications for goal-hover stabilization and wind-disturbance robustness.

Focus Reinforcement learning for autonomous quadrotor pathing
Stack MuJoCo, JAX, PPO, SAC, PETS/MPC
Platform Skydio X2-style quadrotor with lidar and goal-relative observations
Best Result Goal-hover PPO reached 366.8 return and 45.3% success

Overview

This project studied autonomous drone pathing in a randomized 3D MuJoCo environment with capsule obstacles, bounded workspace constraints, and goal-hover success criteria. Each episode randomized the drone start state, target position, and obstacle layout, so the policy had to learn both obstacle-aware local motion and stable final approach behavior.

Project site: Intro to Robot Learning website. Repository: GitHub repo.

Implementation

The learned policy did not command rotor thrusts directly. Instead, it produced normalized translational velocity and yaw-rate commands, while a low-level proportional controller mapped those commands to quadrotor actuation. Observations combined drone state, target-relative geometry, obstacle-relative state, obstacle masks, active-obstacle counts, and multi-beam lidar distances.

I evaluated three planning approaches: PPO as the main on-policy baseline, SAC as the off-policy baseline, and a constrained PETS/MPC-style model-based RL pipeline. The final project also introduced two targeted modifications: goal-hover reward shaping to improve terminal stabilization, and wind-disturbance training to test whether the learned policy could remain effective under external perturbations.

Results

PPO emerged as the strongest and most stable model-free baseline in the completed runs. The baseline PPO policy reached a best return of 80.0 with 25.0% success, while SAC reached 20.7 return with 18.8% success. The strongest overall result came from the goal-hover PPO modification, which improved mean evaluation return to 366.8 and raised success to 45.3%, while also reducing final distance to 1.27 m.

Wind-disturbance training reached 267.6 return and 35.9% success under disturbed dynamics, showing meaningful robustness even though nominal performance stayed below the best still-air goal-hover PPO policy. The main remaining failure mode was final stabilization: the drone often moved toward the target successfully but still overshot, drifted through the goal region, or collided during the last part of the approach.

What I Built

  • Randomized MuJoCo quadrotor navigation task with bounded 3D workspace, capsule obstacles, and goal-hover success logic.
  • PPO, SAC, and model-based RL evaluation pipeline for comparing learning approaches on the same task.
  • Dense shaped reward with progress, obstacle avoidance, safety, smoothness, and terminal-hover components.
  • Goal-hover and wind-disturbance modifications to address terminal stabilization and robustness failures.

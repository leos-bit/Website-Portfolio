Minesweeper Artificial Intelligence

A deep reinforcement learning agent for Minesweeper that learns under sparse feedback and partial observability.

Focus Deep reinforcement learning
Stack Python, TensorFlow, Keras, PyTorch
Challenge Sparse rewards and partial observability
Performance 30%+ win rate on expert difficulty

Overview

Minesweeper is a deceptively hard decision-making problem because each click reveals only limited information, the reward signal is sparse, and early mistakes can end the episode immediately. I used it as a compact testbed for scalable learning, reward design, and training stability.

Implementation

I built the agent in Python using deep learning components across TensorFlow, Keras, and PyTorch. The system used replay buffers, target-network stabilization, CNN-based state analysis, and custom reward functions to improve long-horizon policy learning on higher-dimensional board states.

Results

The final model achieved more than a 30% win rate on expert boards and improved meaningfully over simpler logic-driven strategies. The project showed how reinforcement learning can learn useful structure even in a game where the full state is never directly visible.

What I Built

  • Reinforcement learning environment and reward shaping strategy.
  • Replay buffers, target networks, and training and evaluation tooling.
  • Visualization and analysis tools for model behavior and failure cases.

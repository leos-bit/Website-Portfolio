Minesweeper Artificial Intelligence

Developed an autonomous Minesweeper agent using deep reinforcement learning and convolutional neural networks to make strategic decisions in a partially observable environment.

Overview

Minesweeper is a compact but difficult planning problem with sparse signals, uncertainty, and long-horizon consequences. I used it as a testbed for scalable learning and reward design.

Implementation

I built the agent in Python using TensorFlow, Keras, and PyTorch, with custom reward functions, experience replay, and target-network stabilization. CNN-based state analysis supported policy learning on higher-dimensional board states.

Results

The system achieved over 30% win rate on expert-level boards and improved meaningfully over baseline logic-driven strategies.

My Contributions

  • Designed the reinforcement learning environment and reward shaping strategy.
  • Implemented replay buffers, target networks, and training/evaluation tooling.
  • Built visualization and analysis tools for model behavior and outcomes.
